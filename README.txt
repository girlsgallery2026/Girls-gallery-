GIRLS GALLERY V2
================

Upload the contents of this folder to your GitHub Pages repository.

Files:
- index.html
- styles.css
- script.js
- assets/ (your uploaded images)

The site includes:
Home, Search, Categories, Product page, Cart, Login/Signup demo,
Orders, Customer Feedback, Contact/WhatsApp, and Admin view.

IMPORTANT:
This is a GitHub Pages front-end version. Login, orders, feedback and cart
are stored in the visitor's browser (localStorage). It is NOT a secure
real payment/authentication backend. For real online payments, customer
accounts and centralized orders, connect a backend/database/payment gateway.

PRODUCT PRICES:
The sample prices in script.js are placeholders. Edit the products array
to use your actual prices.
